# Rumos da Liberdade — Projeto Escolar de Ciências Humanas

Site interativo (HTML, CSS e JavaScript puros, sem dependências) com duas etapas:

1. **História em quadrinhos** de 6 páginas, com navegação por botões, bolinhas, setas do teclado e gesto de deslizar no celular.
2. **Portal** com origem histórica, princípios, argumentos, direita no Brasil, conquistas, mitos e verdades, futuro e fontes.

Na última página da HQ há o botão **Saiba mais sobre essas ideias** (abre o portal) e o botão **Veja um vídeo sobre o tema** (abre o vídeo em uma janela).

## Estrutura

```
index.html   → página única (HQ + portal)
style.css    → estilos
script.js    → interações (HQ, portal, menu mobile, vídeo)
images/      → páginas da HQ e bandeira
videos/      → vídeo e imagem de capa
```

## Como rodar

Abra o `index.html` no navegador. Não precisa instalar nada.

## Publicar no GitHub Pages

1. Envie todos os arquivos para um repositório.
2. Em **Settings → Pages**, escolha a branch `main` e a pasta `/ (root)`.
3. O site ficará em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.
